# OpenML Electricity

OpenML data id 151, version 1, fetched by `sklearn.datasets.fetch_openml("electricity", version=1)`
into the scikit-learn data home (`SCIKIT_LEARN_DATA`). The tabular track keeps the numeric
columns, encodes the target and checks the OpenML metadata and the sha256 of the numeric arrays
(`c22ea751...`). Nothing is stored in this directory. The OpenML licence field is "Public"
(see THIRD_PARTY_NOTICES.md).
