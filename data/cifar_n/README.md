# CIFAR-N human labels

`CIFAR-100_human.pt` and `CIFAR-10_human.pt` from UCSC-REAL/cifar-10-100n (Wei et al., ICLR 2022).
The vision track uses `noisy_label` of CIFAR-100 on the pool indices for the CIFAR-100N task and
checks the file's sha256 (`bd2d8040...`, docs/dataset_provenance.md). Redistribution terms of
this copy are tracked in THIRD_PARTY_NOTICES.md.
