# EL2N-adapt、GraNd-adapt 与 CCS-adapt

这些方法补充预测和文本任务上的比较，不改变原 `el2n`、`grand`、`ccs`，也不自动加入任何默认组合。只有显式请求 `el2n_adapt,grand_adapt,ccs_adapt` 时才计算适配分数。原始依据是 Paul、Ganguli 和 Dziugaite 的 *Deep Learning on a Data Diet*（NeurIPS 2021）以及 Zheng 等人的 *Coverage-centric Coreset Selection*（ICLR 2023）。本实现声明任务迁移和梯度代理，不宣称复现原论文的网络、训练轨迹或 AUM 评分。

## 固定定义

预测任务复用 DLinear 的现有早期训练设置。模型在观察到的候选池上训练 `last_layer_warm=10` 轮，种子与该实验格一致，输入特征为 `phi=[trend,1,seasonal,1]`，预测为 `phi @ Theta`。每条窗口的多步残差记为 `e`。

* `el2n_adapt` 按 `||e||₂` 从大到小选择。
* `grand_adapt` 按 `||e||₂ ||phi||₂` 从大到小选择。它等于该 DLinear 全部线性参数对单窗口半平方残差损失的梯度 Frobenius 范数，包含两个偏置。它使用一个早期检查点，没有对原论文的多个独立随机初始化取期望。
* `ccs_adapt` 以同一残差 L2 为难度。固定剔除最难的 10%，分为 50 个等宽层，优先处理较稀疏层，均分剩余记录预算，层内按实验种子随机抽样。该记录预算核心与当前分类 CCS 实现逐种子对照一致。

文本任务只使用固定 revision 的预训练 SmolLM2-135M。逐文档按原上下文 512 截断，计算每个实际预测 token 的概率向量 `p_t`、目标 `y_t` 和输出头输入 `h_t`。令 `e_t=p_t-onehot(y_t)`。

* `el2n_adapt` 使用 `sqrt(mean_t ||e_t||₂²)`。归一化避免仅因文档更长而得分更高。
* `grand_adapt` 使用 `sqrt(mean_t [||e_t||₂² (||h_t||₂²+I_bias)])`，即 token 级直接输出头梯度范数的均方根。它不是文档平均损失的整体梯度范数，不包含 token 梯度间的交叉项、骨干梯度或共享 embedding 权重的输入路径梯度。
* `ccs_adapt` 以同一 token EL2N 难度按域处理，保留最易的 90% 文档，沿用 50 个等宽层和稀疏层优先逻辑，将层间配额单位改为 token。层内随机前缀不超过配额，最后按易到难补足原域预算。最后一个文档可跨过 token 阈值，随后由原文本流水线按完全相同的 token stream cap 训练。若保留的 90% 文档不足以供应原 token 预算，直接失败，不恢复困难文档或减少预算。

所有适配分数只由候选池决定，不读取排序、确认或测试效用来挑分数定义、阈值、层数或训练轮数。原信号计算仍按既有轨道执行，但适配策略不消费其验证回调或损坏标签。文本分数缓存绑定池文件 SHA、记录 ID、模型 revision、上下文与评分版本，使用原子写入。

## 保存与比较

正式补跑使用 v2.2、种子 0/1/2、`--standalone`，每格同时运行三种适配和 Random。需要设置 `--set store.per_unit_scope=all --set save_models=all`，保留分数数组、选择索引、四个划分的逐单元输出、模型和 `selection_info` 中的适配定义。

这产生 6 个任务上的 18 个方法均值，每个均值由 3 个固定种子组成，共 54 个适配结果和 18 个 Random 锚点结果。不能把本次固定种子结果直接混入使用不同种子的旧表。必须先核对数据哈希、划分 ID、预算、学习器、训练配置与锚点，再重算共同种子的均值、配对区间和跨任务统计。结果差或负增益仍然保留。

这些独立适配结果不会改变已有 OmniSelect 的候选组合。若论文要求每个展示基线均为当选组合成员，需要单独冻结扩展组合并重新裁决，不能声称旧当选策略已经比较过新适配。
